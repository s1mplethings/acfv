# Product

ACFV is a single-user, Windows-first creator workflow for turning long recordings into
searchable evidence Moments and reviewed rendered clips. Its current users are VTubers
and video creators managing Twitch or local recordings.

The core flow is capture/import → existing processing pipeline → Creator Library →
Moment lifecycle → retrieval → grounded conversation → clip proposal/render → review →
explicit feedback.

Out of scope for the current MVP are automated publishing, compilations, effects, TTS,
a new database/vector store, and a standalone agent/RAG platform. Live-before-end
segmented ASR and 20+ hour dogfooding remain unverified product gates.
