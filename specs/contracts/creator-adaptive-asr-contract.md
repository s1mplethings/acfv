# Creator Adaptive ASR Contract

Generic ASR remains the canonical base recognizer and fallback. Identity conflict, profile mismatch, missing scoped lexicon, or re-decode failure immediately returns generic output. Hotwords are relevance-limited. Shadow decisions preserve both texts and evidence, cannot self-promote, and cannot overwrite raw/final transcripts or downstream product state. Production requires a per-Creator human-ground-truth gate and explicit user enablement.
