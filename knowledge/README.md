# ACFV Knowledge

Reusable, non-normative project guidance lives here. Contracts live in `specs/`; current
truth lives in `docs/context/`; measured results live in `evidence/`.

- `architecture/`: explanations and trade-offs.
- `domain/`: domain vocabulary and distinctions.
- `operations/`: repeatable operational guidance.
- `troubleshooting/`: issue memory and failure diagnosis pointers.
- `decisions/`: durable design rationale.
